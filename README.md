## O que é

O Movie Roller é um aplicativo Android que permite descobrir filmes por meio de um sistema de sorteio aleatório. Ao pressionar o botão "Clique Aqui", o aplicativo seleciona um filme e exibe seu respectivo pôster na tela.

Desenvolvido com Kotlin e Jetpack Compose, o projeto utiliza gerenciamento de estado para atualizar dinamicamente os pôsteres a cada sorteio.

Atualmente, as imagens são armazenadas nos recursos locais do aplicativo, com possibilidade de expansão para integração com APIs de catálogos cinematográficos.
